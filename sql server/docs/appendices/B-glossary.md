# Appendix B — Glossary

| Term | Definition |
|------|------------|
| **Instance** | One installed SQL Server engine service |
| **Database** | Container for user objects |
| **Schema** | Namespace (`dbo`, `shop`) |
| **T-SQL** | Transact-SQL dialect |
| **DDL** | Data Definition Language (`CREATE`, `ALTER`, `DROP`) |
| **DML** | Data Manipulation Language (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) |
| **PK / FK** | Primary / Foreign key |
| **Clustered index** | Table row order (one per table) |
| **Nonclustered index** | Separate structure pointing to rows |
| **Sargable** | Predicate allows index seek |
| **RPO** | Recovery Point Objective — max acceptable data loss |
| **RTO** | Recovery Time Objective — max acceptable downtime |
| **AG** | Always On Availability Group |
| **DMV** | Dynamic Management View |
| **XE** | Extended Events |
| **CTE** | Common Table Expression (`WITH`) |
| **RLS** | Row-Level Security |
| **TDE** | Transparent Data Encryption |
