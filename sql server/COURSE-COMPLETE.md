## Skills checklist

- Install, connect, write T-SQL through advanced objects  
- Design ERD/DFD and implement schema  
- Tune queries (indexes, plans, Query Store)  
- Secure with roles and least privilege  
- Backup, restore, monitor, and document runbooks  
- Explain HA options and Azure SQL differences
