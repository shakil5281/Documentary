## Learning outcomes (course-level)

By the end you can:

1. Explain microservices from basics through advanced production patterns
2. Define service boundaries using DDD (bounded context, aggregates, context map)
3. Design sync/async communication, data management, and Saga workflows
4. Analyze **scalability**, **performance**, and **time complexity** of distributed architectures
5. Apply resilience, security, observability, and deployment strategies
6. Make informed monolith vs microservices decisions with documented trade-offs
7. Complete a capstone e-commerce architecture with latency budget and complexity analysis
8. Draw **data flow diagrams** and **system design** diagrams for distributed systems

**Reference guide (read with Part II):** [DATA-FLOW-AND-SYSTEM-DESIGN.md](docs/DATA-FLOW-AND-SYSTEM-DESIGN.md)
